## About this repository
The website is built by GitHub Pages from:
- `_data/portfolio.yml` - **all the content** (edit this to update the site)
- `index.html` - the page layout
- `assets/css/portfolio.css` - the design (font: Inter, SIL Open Font License, in `assets/fonts`)

Preview locally before pushing: `python tools/preview.py` (needs Python with Jinja2 and PyYAML), then open the
address it prints.
